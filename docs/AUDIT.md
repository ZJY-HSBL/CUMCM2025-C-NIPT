# 2025 CUMCM C 题参赛文件事后审查

**审查范围：** 压缩包中的 54 页论文、4 份 Python 代码、题目说明、原始工作簿与若干处理结果。**审查性质：** 静态代码核对、附件字段/标签核对和基本语法检查；未逐一成功重跑原论文全部数值结果。

## 核心问题（按严重程度）

### 严重 1：问题一与问题二跨模型变量量纲不一致

`a_1_1.xlsx` 中“孕周”“BMI”“Y染色体浓度”均已进行 Z-score 标准化（例如首条孕周为 `-1.2243`，而非实际 `11.8571` 周）。原程序 `question_1.py` 后段的非线性混合效应模型基于这些标准化量拟合。`question_2.py` 中 `y_chromosome_concentration()` 却直接使用未经标准化的实际孕周和 BMI，并以数值 `4` 作为“4%”阈值。两者不是同一量纲。结果可能严重偏离真实达标时间。论文报告的 `12.05`、`13.33` 周不能在未反标准化、重新拟合和验证前视为可靠时点。

另外，问题一的 `fittedvalues` 包含拟合样本的个体随机效应；以其计算的训练内 `R²=0.8035` 不能解释为对新孕妇的预测精度。

**修正方向：** 统一原始浓度比例（阈值 `0.04`）、百分数（阈值 `4`）和标准化变量；保存、应用训练集的 scaler 或直接重拟合原始单位模型。随机效应模型需要按孕妇代码分组进行真正的样本外验证。此处未擅自重算结果。

### 严重 2：问题二的优化目标不是“最小潜在风险”

`question_2.py` 的 PSO 目标是 `abs(predicted_y - 4)`，搜索区间为 `[10,25]`。它仅求接近阈值的根，而不是在预测达标率/检测误差等约束下最小化检测时点和延期风险。`question_2.py` 第 19–43 行附近。即使浓度单位修正，仍须重新定义目标函数、机会约束与误差处理。

### 严重 3：问题四的正常标签丢失，性能验证失真

原始女胎表有 `605` 条数据，其中非整倍体（AB 列）`67` 条非空标记，另外 `538` 条为空白；题目明确**空白即为无异常**。`question_4.py` 的 `map_aneuploidy()` 将空值映射为 `pd.NA` 而不是正常类别 `0`，进而 `validate_model()` 仅针对非空标签验证。这样不能得到完整的混淆矩阵、特异度、F1、Kappa，不能证明对正常/异常女胎有可信的判别能力。

该脚本 `map_health()` 判断 `'健康' in s` 早于“不健康”，存在子串误判；而原附件健康标签为 `是`，不在该函数的正类映射中，出生结局也未被有效验证。建议先规范标签、明确任务定义，再按**孕妇代码**而非检测记录做训练集/测试集拆分并报告真实分类指标。

### 高 4：问题三 Bootstrap 不是有放回的个体重采样

`question_3.py` `bootstrap_ga_star()` 先抽取孕妇 ID，再使用 `set(...)` 去重和 `isin(...)` 筛选观测。重复抽中的个体没有重复进入重拟合样本，改变了标准 Bootstrap 的权重分布；置信区间统计意义不能按常规 Bootstrap 解释。应为重复抽中个体生成独立副本/组标识并按重采样频率重拟合。

### 高 5：问题三生存时间建模及验证较弱

`construct_time_interval()` 生成的达标区间被 `build_survival_table()` 取中点/上限替换成单一事件时间，不能等同于正确拟合区间删失模型。对于未达标个体，代码统一把删失时间设置为 25 周，而非其最后观测孕周。论文给出的 C-index 为 `0.528`、`0.526`，接近随机排序的 `0.5`；`≥0.52` 不能据此认定为通用的临床有效性标准。

### 中 6：数据重复、边界分组及结果描述

`question_2.py` 对检测记录进行 BMI 聚类，同一孕妇重复检测可能让多次记录者占更高权重。`check_cluster_boundary()` 会把冲突簇的“最小值”人为改成上个簇最大值加 `1e-4`，但没有重新分配原记录，也未证明分界连续覆盖所有 BMI。论文问题三先称 K=3，后剔除样本数少的第三组，最终报告两组；未说明剔除群体的外推范围，应记录覆盖率。

### 中 7：问题四参数和结论表述

论文摘要称孤立森林每棵树样本数为 `230`，但 `question_4.py` 实际采用 `max_samples=min(0.25, len(X))`（浮点比例 `0.25`），并非固定 230。按照分位数 `Q90` 定高风险，约 10% 的高风险比例近似由分位数规则定义，不能用该比例在 `contamination` 扰动时恒定来证明模型临床稳健。此外，论文中“完全满足临床应用需求”等表述缺少外部临床验证支撑。

### 中 8：工程可复现性

四份脚本有语法可解析，但依赖本地相对路径和预生成的中间 Excel 文件，缺少版本锁定、固定输入清单以及完整运行日志。`question_1.py` 存在重名函数（`GleanData_Question_1` 两次定义）、未启用流程里的错误引用 `data.WeekAndDay_to_Week` 和依赖历史中间数据的问题。原始源代码在本仓库不做覆盖修改，避免与比赛当时提交版本混淆。

## 审查结论

四问的方法组合具备比赛解题的基本结构，但**问题二的时点结论与问题四的异常判定有效性目前不可视为经独立验证**。建议优先按“量纲统一→结果重算→个体级验证→错误分析→文稿同步更正”的顺序修订。所有数值均为原论文报告值或源附件可直接核对的描述，未伪造重跑成绩。
